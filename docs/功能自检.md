# 功能自检报告

自检时间：2026-10-26　自检对象：字帖工坊 v1.0.0（提交前全量）

## 一、为什么要重新自检

上一版 README 里列了二十多条能力，但那些条目是「写代码时的意图」，不是「跑起来的结果」。
典型例子是**简繁转换**：开关点了没反应，界面上没有任何提示，代码里也看不出问题——
因为 `_to_traditional()` 用 `try/except Exception` 包着 `import zhconv`，没装依赖时
直接 `return text` 把原文还回来，等于开关被静默吃掉了。

所以这次换了判定方式：**不看代码写没写，只看渲染结果变没变**。

## 二、自检方法

对每个可调参数，构造「基线」与「只改这一项」两个 `SheetParams`，各渲染第 1 页，
比较六项指纹：

| 指纹 | 取自 | 说明 |
|---|---|---|
| 像素哈希 | `render_page(0).tobytes()` 的 SHA1 | 最直接的「画面变了没」 |
| 画布尺寸 | 同上 | 纸张、dpi 类参数只能靠它体现 |
| 页数 | `len(sheet.pages)` | 分页、行数、模式类参数 |
| 字数 | `sheet.char_count` | 编排类参数 |
| 缺字 | `missing_report()[0]` | 字体覆盖类参数 |
| 借用字 | `missing_report()[1]` | 回退链是否真的补上了字 |

六项全部与基线相同 → 判为**无效参数**。参数之外，另有一组「规则断言」检查结果对不对，
例如标点有没有真的避开行首、关掉回退时有没有如实报缺字。

复跑：`python tools/selftest.py --api`

## 四、发现并修复的问题

### 1. 简繁转换完全无效（用户报告）

**现象**：勾选「转繁体」，预览毫无变化。

**原因**：`_to_traditional()` 里 `except Exception: return text` 吞掉了
`ModuleNotFoundError`。开发机装了 `zhconv` 所以看起来正常，换一台没装的机器
（或另一个 venv）就彻底失效，而且没有任何提示。次生问题还有两个：
标题不参与转换（正文繁体、标题仍是简体），以及缺字检查仍按简体原文做，
「牀 / 頭 / 鄉」这类繁体字缺字形时不报警。

**修复**：
- 没装依赖时抛 `TraditionalUnavailable`，接口层转成明确报错
  `转繁体需要 zhconv，请先执行 pip install zhconv`；
- `/api/meta` 增加 `capabilities.traditional`，前端据此把开关置灰并写明原因，
  避免「点了没反应」这种最难排查的状态；
- 标题同步转换，缺字检查改在转换后的文本上做；
- 顺手修了 zhconv 把量词「里」一律转成「裏」的问题（公里 → 公裏 → 已修正回公里）。

**验证**：`头发发热 → 頭髮發熱`、`一公里，千里之行 → 一公里，千里之行`，
繁体预览与简体预览的像素哈希不同；模拟卸载 zhconv 后开关置灰、接口 400。

### 2. 「保留标点」对中文文本无效

**现象**：关掉「保留标点」，正文里的「，。？！」一个没少。

**原因**：`normalize()` 里全角标点走的是「无条件保留」分支，只有半角 `,.;:?!`
受 `keep_punct` 控制。中文用户粘贴的几乎全是全角标点，所以这个开关等于不存在。

**修复**：把全角与半角标点合并成 `ALL_PUNCT` 统一受开关控制，宣传语、字形描红、
单字练习的标点判断也统一改用这个集合。

**验证**：`春眠，不觉晓。OK? yes` 关开关后输出 `春眠不觉晓OKyes`。

### 3. 避头尾禁则方向反了

**现象**：5 格排「春眠不觉晓，处处闻啼鸟。」，第二行以「，」开头——正是禁则要避免的情况。
6 格时又会把「晓」和「，」一起拖到下一行，白白浪费格子。

**原因**：原实现是「一个字一个字往行里塞，塞满后再看最后一个字是不是标点」。
这个时机太晚了：标点真正的危险位置是**下一行的第一个字**，而那时它还没被塞进去。

**修复**：改成先按格数算出候选断点，再检查断点后面的字符：
是标点就把断点前移一格（连续标点如「？！」「……」一次处理到位）；
行尾若是开引号左括号，把断点再前移一格。断点只前移不后移，行宽永远不超过格数。

**验证**：对 2–12 格共 11 种格宽遍历「春眠不觉晓，处处闻啼鸟。夜来风雨声，
花落知多少？（孟浩然）」，行首标点 0 例、行尾开引号 0 例；关掉禁则时断行结果与
开启时不同（开关不是摆设）。

## 五、复核通过、未改动的部分

以下是怀疑过但实测正常的点，记录下来备查：

- **预览与导出页数一致**：预览走 150dpi、导出走 300dpi，自动行数按像素整除计算，
  理论上可能出现「预览 2 页、导出 3 页」。对 3 种纸张 × 11 种格边长 × 5 种列数
  共 165 种组合遍历，页数与字数完全一致（毫米与像素同比缩放，不产生漂移）。
- **PDF 页面尺寸**：导出 A4 实测 595.2 × 841.92 pt，与 210 × 297mm 吻合，打印不变形。
- **缺字回退**：主字体缺「龘靐齉」时自动从字体链借字并列出借用清单；
  关掉回退则如实报缺字，两种情况互不干扰。
- **字体上传**：非中文字体返回 400 并删除落盘文件；同一文件重复上传按 SHA1 复用，
  不会在 `backend/fonts/` 里堆副本。
- **分册导出**：24 字按每册 12 字拆成 2 册，zip 内文件名与册序一致。

## 六、仍然存在的限制

- 简繁转换是字表 + 有限词组表，不是分词模型，个别多音字仍会误转，付印前需通读。
- 「按标点断句」只在每句都放得进一行时生效，否则整段退回硬切。
- 内置只有一款字体；Linux 服务器没有系统字体时，选择器只剩内置楷书一项。
- 上传字体接口无鉴权，仅适合本地/内网使用，公网部署前需自行加限流与鉴权。
